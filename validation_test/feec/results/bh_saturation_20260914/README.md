# BH saturation audit and native energy-Newton regression

This follow-up does not change the solver, BH input policy, test material,
or the accepted ESRF6 three-engine evidence. It independently checks the
reported synthetic-table properties and exercises the existing nine native
energy-Newton tests on hibino using the repaired candidate wheel.

## Curve findings

`curve_report.json` is generated by `validation_test/feec/bh_saturation_audit.py`.
The audit executes selected production scalar helpers without importing the
NGSolve/native package. It checks extrema of the actual piecewise-polynomial
interpolant, not just table knots or a dense sampling grid.

- The synthetic regression table has negative differential susceptibility.
  Its interpolated peak magnetization is 1.641130e6 A/m at H=29637.05 A/m;
  its endpoint-based cap is 9.894368e5 A/m, 60.2900% of that peak.
  The differential inverse slope jumps by about 1.277079e6 at the cap.
- The shipped 100-row `em_sample_bh.txt` has nondecreasing magnetization
  throughout the actual interpolant, not only at its knots.
- Nodal monotonicity alone is insufficient: B-PCHIP interpolation can produce
  negative differential susceptibility between monotone M knots. A focused
  counterexample locks this distinction.
- Constant zero magnetization is not negative susceptibility, but cannot be
  inverted as a single-valued H(M) law. The diagnostic records that exception.

These are constitutive-curve properties, not proof that Newton fails, nor an
explanation of the historical settled-acceptance behavior. The synthetic table
remains an algorithmic stress fixture, not a validated physical saturation law.
No input is silently repaired, and no new public API is introduced.

7.93e-6 A/m (about 8.0e-12 relative). All recorded energy-Newton solves

convergence flag. A lightweight evidence-replay test checks these properties;
it explicitly treats the separate Picard-mass-Riesz test under its own contract.
The default and tuned paths both converge. The tuned combination is substantially
slower here and is not recommended as a speed improvement on this fixture.

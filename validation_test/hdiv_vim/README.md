# HDiv-VIM Validation Evidence

This directory owns the checked numerical records used by the public curved
HDiv-VIM showcase. The executed notebook under `docs/hdiv_vim` embeds its
tables and figures without writing result JSON beside itself.

The three JSON files preserve the analytic-sphere, nonlinear-field, and
flat-Radia-versus-curved-HDiv comparisons. Their corresponding calculations
remain visible in the public notebook; production performance evidence belongs
to the dedicated HDiv benchmark lanes.

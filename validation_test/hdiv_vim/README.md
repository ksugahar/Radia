# HDiv-VIM Validation Evidence

This directory owns the checked numerical records used by the public curved
HDiv-VIM showcase. The executed notebook under `docs/hdiv_vim` embeds its
tables and figures without writing result JSON beside itself.

The numerical JSON files preserve the analytic-sphere, nonlinear-field, and
flat-Radia-versus-curved-HDiv comparisons. The committed `vol-check` report
locks the C-type electromagnet mesh labels, element quality, boundary ownership,
and CAD-to-mesh measure checks. Corresponding calculations and rendered results
remain visible in the public notebooks; production performance evidence belongs
to the dedicated HDiv benchmark lanes.

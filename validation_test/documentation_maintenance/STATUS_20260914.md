## Reproduce the structural audit

Run `audit_public_notebooks.py` from this directory or the repository root.
`--output <path>` emits generated JSON. `--live-bibliography <path>` compares the
file at a separately verified live source; it does not establish a process
reload. Run the focused tests with
`python -m pytest packages/radia-mcp/tests/test_document_meta_notebook_audit.py -q`.

The repository contains substantial unrelated in-progress changes. This step
does not stage or commit them, change numerical binaries, interrupt MATLAB/CAD
sessions, or claim that a live MCP deployment has completed.

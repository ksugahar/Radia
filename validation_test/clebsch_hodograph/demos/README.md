# Clebsch/Hodograph demo records

These JSON files are durable numerical records emitted by the readable demo
scripts under `docs/clebsch_hodograph/demos/`. The scripts write here through
their shared `_validation_output.py` helper; they no longer create docs-local
result sidecars.

The public `docs/clebsch_hodograph/public_demo.ipynb` embeds the selected source
and figures. Physics acceptance remains in the corresponding FEEC validation
tests; this directory preserves the generated records for inspection and MCP
knowledge.

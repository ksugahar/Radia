# Section Optics Validation

This directory owns checked section-optics rows and durable design evidence.
`section_optics_design_results.json` preserves the full TURBO design record;
the executed notebook under `docs/section_optics` is the public,
result-embedded presentation and does not write a sidecar.

The former notebook-hash stamping script was retired. Git history records the
notebook revision, while validation artifacts carry runtime and solver
provenance without requiring a byte-for-byte notebook checksum.

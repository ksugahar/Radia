# Retained detailed studies

These notebooks preserve the earlier calculations and saved outputs from the
six application pages before those pages became result readers. They are
historical numerical studies, not evidence that every cell was rerun in the
selected campaign. The fresh focused runs are in [../results/](../results/).

The directory hierarchy mirrors `docs/`. Existing relative imports and artifact
paths in these historical notebooks still expect the corresponding original
`docs/<topic>/` working directory. To execute one, set the notebook executor's
working directory explicitly to that topic; do not assume its present directory
is an execution root. Follow the compute-host rules, inspect dependencies, and
keep any resulting outputs separate from the accepted campaign.

The analytical and theoretical narrative can be read without executing cells.
The current user-facing pages load saved results and do not run these studies.

# wpt — Wireless Power Transfer

PEEC-based wireless power transfer (WPT) coil system analysis.

## Files

| File | Description |
|------|-------------|
| `demo_wpt.py` | WPT system demo (coupling coefficient, S-parameters, skin effect) |
| `wpt_85khz_cubit_mesh.py` | 85 kHz WPT model with Cubit mesh |
| `wpt_85khz_with_shield.py` | 85 kHz WPT model with shield conductor |

## Outputs

- `demo_wpt_basic.png` — Basic WPT analysis
- `demo_wpt_multi_turn.png` — Multi-turn coil
- `demo_wpt_s_params.png` — S-parameters
- `demo_wpt_skin_effect.png` — Skin effect
- `demo_wpt_variable_k.png` — Variable coupling coefficient

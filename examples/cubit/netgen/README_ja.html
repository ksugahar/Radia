Netgen/NGSolve サンプル

このフォルダには、CubitメッシュをNetgen/NGSolveにエクスポートするサンプルが含まれています。

基本的な制限事項

CubitはACISカーネル、Netgen/NGSolveはOpenCASCADE (OCC)を使用しています。

これらのCADカーネルはジオメトリを直接共有できません：

  • ACISからOCCへの直接的なジオメトリ転送は不可
  • データ交換にはSTEP/IGES中間フォーマットが必要
  • STEPは円筒面/球面にシーム線を追加（STEP仕様）
  • mesh.Curve()はNetgen生成メッシュのみが持つUVパラメータを必要とする

STEPが問題を引き起こす理由

STEPは「最小公倍数」フォーマットです。エクスポート時：

  1. シーム線の追加：円筒（ACISでは1つの面）がSTEPでは2つ以上の面になる
  2. トポロジーの変化：面/エッジIDがACISとOCCで異なる
  3. 精度の低下：浮動小数点座標がわずかにずれる可能性

STEPの再インポート回避策を使用しても、根本的な不一致は残ります：CubitのメッシュはACISジオメトリで生成されましたが、NGSolveのmesh.Curve()はOCCジオメトリを使用します。UVパラメータは転送できません。

現在の実用的な解決策

これらの制限を踏まえ、2つの実用的なアプローチを提供します：

アプローチ 利点 欠点
Gmsh 2次要素 シンプル、高精度（0.001%） 2次要素に限定
SetDeformation 解析的形状で正確、Wedge対応 手動、形状固有

どちらも完璧ではありませんが、工学的応用において十分な精度を達成できます。

推奨ワークフロー：Gmsh 2次要素

曲面には、ReadGmsh()とGmsh 2次要素を使用します：

import cubit
import cubit_mesh_export
from netgen.read_gmsh import ReadGmsh
from ngsolve import Mesh

# 1. Cubitでジオメトリとメッシュを作成
cubit.init(['cubit', '-nojournal', '-batch'])
cubit.cmd("create cylinder height 2 radius 0.5")
cubit.cmd("volume all scheme tetmesh")
cubit.cmd("volume all size 0.1")
cubit.cmd("mesh volume all")

# 2. 2次要素でブロックを登録
cubit.cmd("block 1 add tet all")
cubit.cmd("block 2 add tri all")
cubit.cmd("block 1 element type tetra10")
cubit.cmd("block 2 element type tri6")

# 3. Gmshにエクスポートし、NGSolveに読み込み
cubit_mesh_export.export_Gmsh_ver2(cubit, "mesh.msh")
mesh = Mesh(ReadGmsh("mesh.msh"))

このワークフローの特徴：

  • Cubitの2次要素を使用（曲面上の中間エッジノード）
  • CADジオメトリ交換なし - STEPの問題を完全に回避
  • Tet、Hex、Wedge、Pyramidに対応

精度（体積誤差）

要素タイプ 1次要素 2次要素（Gmsh）
Tet 約1.4% 0.001%
Hex 約1.6% 0.002%
Wedge 約1.6% 約1.1%（注意）
注意：CubitはWedgeの中間エッジノードを曲面に投影しません。

代替手法：SetDeformation

解析的形状とWedge要素には、SetDeformationが正確な投影を提供します：

import cubit_mesh_export
from netgen.occ import OCCGeometry
from ngsolve import Mesh

# OCCジオメトリ参照でエクスポート
geo = OCCGeometry("geometry.step")
ngmesh = cubit_mesh_export.export_netgen(cubit, geometry=geo)
mesh = Mesh(ngmesh)
mesh.Curve(1)  # 線形のみ！

# 解析的変形を適用
cyl_boundaries = cubit_mesh_export.detect_cylinder_boundaries(mesh, radius=0.5, axis='z')
cubit_mesh_export.apply_cylinder_deformation(
    mesh, radius=0.5, boundary_names=cyl_boundaries, order=2, axis='z'
)

比較

ケース Gmsh 2次 SetDeformation
円筒上のTet 0.001% 0.02%
円筒上のWedge 1.1% 0.02%

SetDeformationを使用する場合：

  • 曲面上のWedge要素（誘導加熱など）
  • 正確な解析的投影が必要な場合（円筒、球、円錐、トーラス）

STEP再インポート回避策

STEPジオメトリでexport_netgen()を使用する場合、トポロジーを揃えるためにメッシュ作成前にSTEPを再インポートします：

# 1. ジオメトリを作成
cubit.cmd("create cylinder height 2 radius 0.5")

# 2. STEPにエクスポート
cubit.cmd('export step "geometry.step" overwrite')

# 3. STEPを再インポート（CubitがOCCと同じシーム線を認識）
cubit.cmd("reset")
cubit.cmd('import step "geometry.step" heal')

# 4. シーム線を考慮したジオメトリをメッシュ化
cubit.cmd("volume all scheme tetmesh")
cubit.cmd("mesh volume all")

これにより面の境界が揃いますが、UVパラメータがないためmesh.Curve(2+)は機能しません。

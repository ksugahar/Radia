# 円筒座標系における完全ケルビン変換の導出（r方向・z方向両方）

## 1. 問題設定

半径 a、高さ h の円筒境界において、r方向とz方向の両方にケルビン変換を適用する場合を考える。

## 2. 座標変換

円筒座標 (r, θ, z) において、以下のケルビン変換を定義する：

**r方向の変換：**

r' = a²/r

**z方向の変換：**

z' = h²/z

**θ方向：**

θ' = θ （変換なし）

## 3. 線要素の導出

線要素 h_i は座標変換のヤコビアンから計算される。

### r方向の線要素

r' = a²/r より：

dr'/dr = -a²/r²

外部領域の座標 r' で表すと r = a²/r' なので：

h'_r = -a²/r'²

### z方向の線要素

z' = h²/z より：

dz'/dz = -h²/z²

外部領域の座標 z' で表すと z = h²/z' なので：

h'_z = -h²/z'²

### θ方向の線要素

θ' = θ より変換なし。ただし r が r' に変換されるので：

h'_θ = a²/r'

## 4. 線要素のまとめ

### 内部領域

- h_r = 1
- h_θ = r
- h_z = 1

### 外部領域

- h'_r = -a²/r'²
- h'_θ = a²/r'
- h'_z = -h²/z'²

## 5. 面要素の計算

### 内部領域

- h_θ × h_z = r × 1 = r
- h_z × h_r = 1 × 1 = 1
- h_r × h_θ = 1 × r = r

### 外部領域

- h'_θ × h'_z = (a²/r') × (-h²/z'²) = -a²h²/(r'z'²)
- h'_z × h'_r = (-h²/z'²) × (-a²/r'²) = a²h²/(r'²z'²)
- h'_r × h'_θ = (-a²/r'²) × (a²/r') = -a⁴/r'³

## 6. 計量（Metric）の計算

論文の定義 g_i = (h_j × h_k)/h_i に従う。

### 内部領域

- g_r = (h_θ × h_z)/h_r = r/1 = r
- g_θ = (h_z × h_r)/h_θ = 1/r
- g_z = (h_r × h_θ)/h_z = r/1 = r

### 外部領域

- g'_r = (h'_θ × h'_z)/h'_r = [-a²h²/(r'z'²)] / [-a²/r'²] = h²r'/(z'²)
- g'_θ = (h'_z × h'_r)/h'_θ = [a²h²/(r'²z'²)] / [a²/r'] = h²/(r'z'²)
- g'_z = (h'_r × h'_θ)/h'_z = [-a⁴/r'³] / [-h²/z'²] = a⁴z'²/(h²r'³)

## 7. 材料特性の導出

材料特性は計量の比から導出される：

μ'_i/μ_i = ε'_i/ε_i = σ'_i/σ_i = -g'_i/g_i

変換関係 r = a²/r', z = h²/z' を用いて、内部領域の計量を外部座標で表す：

- g_r = r = a²/r'
- g_θ = 1/r = r'/a²
- g_z = r = a²/r'

### r成分

μ'_r/μ_r = -g'_r/g_r = -[h²r'/(z'²)] / [a²/r'] = -h²r'²/(a²z'²)

符号を整理すると（物理的に正の透磁率）：

**μ'_r/μ_r = (r'/a)² × (h/z')²**

### θ成分

μ'_θ/μ_θ = -g'_θ/g_θ = -[h²/(r'z'²)] / [r'/a²] = -a²h²/(r'²z'²)

**μ'_θ/μ_θ = (a/r')² × (h/z')²**

### z成分

μ'_z/μ_z = -g'_z/g_z = -[a⁴z'²/(h²r'³)] / [a²/r'] = -a²z'²/(h²r'²)

**μ'_z/μ_z = (a/r')² × (z'/h)²**

## 8. 最終結果

### 外部領域における材料特性（r, z両方向ケルビン変換）

| 成分 | 透磁率比 μ'/μ | 導電率比 σ'/σ | 誘電率比 ε'/ε |
|------|---------------|---------------|---------------|
| r方向 | (r'/a)²(h/z')² | (r'/a)²(h/z')² | (r'/a)²(h/z')² |
| θ方向 | (a/r')²(h/z')² | (a/r')²(h/z')² | (a/r')²(h/z')² |
| z方向 | (a/r')²(z'/h)² | (a/r')²(z'/h)² | (a/r')²(z'/h)² |

### 具体的な式

**μ'_r = μ_r × (r'/a)² × (h/z')²**

**μ'_θ = μ_θ × (a/r')² × (h/z')²**

**μ'_z = μ_z × (a/r')² × (z'/h)²**

導電率 σ と誘電率 ε についても同様の式が成り立つ。

## 9. 背景場の変換

### 内部領域の背景場

一様なz方向磁場を考える：

**H_s** = (0, 0, H₀)

対応するスカラーポテンシャル：

φ_s = -H₀ · z

### 外部領域の背景場の導出

座標変換 z = h²/z' を用いると、外部領域でのポテンシャルは：

φ'_s = -H₀ · (h²/z')

外部領域での磁場 H'_s = -∇'φ'_s を計算する。線要素 h'_z = -h²/z'² を考慮すると：

∂φ'_s/∂z' = -H₀ · h² · (-1/z'²) = H₀ · h²/z'²

H'_s,z = -∂φ'_s/∂z' × 1/h'_z = -(H₀ · h²/z'²) / (-h²/z'²) = -H₀

### 結果

**外部領域での背景場：**

**H'_s** = (0, 0, -H₀)

つまり、z方向のケルビン変換により、背景場のz成分は**符号が反転**する。

### 物理的解釈

- ケルビン変換 z' = h²/z は z = ±h で不変点を持ち、z > h は z' < h に、z < -h は z' > -h にマッピングされる
- 変換のヤコビアン dz'/dz = -h²/z² が負であるため、z方向が反転する
- これにより、背景場のz成分も符号が反転する

## 10. 軸対称問題への適用

### 等方性材料の場合

軸対称問題で等方性材料（μ_r = μ_θ = μ_z = μ）を扱う場合、透磁率テンソルは：

- μ'_r = μ × (r'/a)² × (h/z')²
- μ'_z = μ × (a/r')² × (z'/h)²

### 簡略化：μ'_r = μ'_z となる条件

μ'_r = μ'_z となるためには：

(r'/a)² × (h/z')² = (a/r')² × (z'/h)²

これを整理すると：

(r'/a)⁴ = (z'/h)⁴

つまり r'/a = ±z'/h の場合のみ成立し、一般には成立しない。

### 平均的な等方透磁率の近似

厳密には異方性だが、近似として等方透磁率を使う場合：

μ'_eff = μ × (a/r') × (h/z')  （幾何平均）

または

μ'_eff = μ × (a/r')² × (h/z')²  （θ成分を採用）

## 11. 物理的解釈

- 全ての成分が r' と z' の両方に依存する
- r方向成分：r'² に比例、z'² に反比例
- θ方向成分：r'² に反比例、z'² に反比例
- z方向成分：r'² に反比例、z'² に比例

## 12. z-offset方式との非互換性（重要）

z-offset方式（外部領域をz方向にオフセットして配置し、周期境界条件で接続する方式）では、円筒Kelvin変換は**使用できない**。

### 問題点

z-offset方式では、内部領域と外部領域が同一形状の境界で接続される。しかし円筒Kelvin係数は境界上で連続性を保てない。

**境界での連続性条件**：

- ν_r = 1 となる軌跡: z' = h × (r'/a) （直線）
- ν_z = 1 となる軌跡: z' = h × (a/r') （双曲線）

これら2つの曲線は **(r', z') = (a, h) の1点でのみ交差**する。

つまり、**矩形境界の角の1点を除き、境界上のすべての点で材料定数が不連続**となる。

### 数値例（a = 1m, h = 0.5m）

| 位置 | 内部 (ν_r, ν_z) | 外部 (ν_r, ν_z) | 不連続比 |
|------|-----------------|-----------------|----------|
| r=0.1, z=h | (1, 1) | (100, 0.01) | 100倍 |
| r=0.5, z=h | (1, 1) | (4, 0.25) | 4倍 |
| r=a, z=h | (1, 1) | (1, 1) | 連続（角のみ） |
| r=a, z=0 | (1, 1) | (0, ∞) | 発散 |

### 等方性条件

異方性材料を等方的にする条件 (ν_r = ν_z) は：

z' = (h/a) × r'

これは原点を通る直線であるが、この上でも ν_r = ν_z ≠ 1 であり、境界での連続性は満たされない。

### 結論

**z-offset方式で有限要素解析を行う場合、円筒Kelvin変換は適用不可能**。

代わりに以下の選択肢がある：

1. **球面Kelvin変換（等方性）**: z-offset方式と互換性あり。半円（球面断面）境界を使用
2. **真の円筒Kelvin変換**: r方向・z方向両方で座標反転が必要。実装が複雑

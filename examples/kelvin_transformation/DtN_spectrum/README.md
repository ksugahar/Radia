# DtN-spectrum view of Kelvin-transformation coarse-mesh accuracy

These standalone scripts are the verified experiments behind the
`dtn_coarse_mesh` knowledge module
(`packages/radia-mcp/src/radia_mcp/radia_ngsolve/knowledge/dtn_coarse_mesh.py`).

Their practical "where to spend elements" synthesis is consolidated in the MCP
topic `kelvin_transformation(topic="mesh_control")`: the Gamma-conforming mesh
constraint (copy-mesh / Identify) plus the six measured pillars below
(exterior volume is free, floor = Curve order, `p >= n` & p-vs-h, optimal
`R/a ~ 3`, corner `hp`, DoF-cost `1/45`), confirmed in 2D on the `-n/R` ladder.

**Idea.** Every open-boundary closure (Kelvin / BEM / PML / Robin) approximates the
one exterior Dirichlet-to-Neumann (Steklov–Poincaré) operator `Λ_ext`, whose sphere
eigenvalues are the mesh-independent ladder `λ_n = −(n+1)/R` (3D), `−n/R` (2D). The
discrete matrix `Λ_h` reproduces the LOW-degree eigenvalues accurately and almost
independently of mesh size `h`; the per-mode defect grows with degree `n`. Because a
compact source's field is dominated by low multipoles, a coarse Kelvin mesh already
resolves everything that matters — the empirical coarse-mesh accuracy, read off the
spectrum.

Most scripts PRINT their result (self-asserting, no files written); the benchmark /
figure scripts (`act7_22`, `act8_05`, `act8_14`) also write a committed `.json` (+ a
regenerable, git-ignored figure). They depend only on `numpy` / `scipy` / `ngsolve` /
`netgen`, the open `radia_mcp.radia_ngsolve` helpers (`bem_integral`,
`fem_bem_coupling`), and — for the Track-A time-axis acts — the shipped
**`radia.open_boundary`** module (below).

**Start here (the headline).** The whole comparison is consolidated in ONE verified
table — every closure × every regime × every multipole on a single yardstick, the
per-mode DtN-spectral defect `d_n` — by **`act7_22_dtn_spectrum_consolidated.py`**
(datasheet: [`docs/open_boundary/DTN_SPECTRUM_COMPARISON.md`](../../../docs/open_boundary/DTN_SPECTRUM_COMPARISON.md)).
The Track-A time-axis result (the eddy / wave exterior DtN realized EXACTLY as a
Cauer / CLN ladder) is **productionized** as the `radia.open_boundary` module
(`eddy_dtn`, `wave_dtn`, `cauer_ladder`, `kelvin_fem_radial_dtn`, …; goldens
`tests/open_boundary/`) — the `act6_*` scripts here are its verified experiments.

## The one story — a reading guide (read in this order)

Every open boundary is the SAME object: the exterior Dirichlet-to-Neumann
(Steklov–Poincaré) operator `Λ_ext` on the truncation surface Γ, whose sphere
spectrum is the ladder `λ_n = −(n+1)/R` (3D) / `−n/R` (2D). These scripts are **one
story about that operator** — *read* its spectrum, *build* it sparsely, *realize* it in
time, *extend* it to radiation, and *design* with it. The detailed table follows; this
is the arc (each script self-asserts and prints its result).

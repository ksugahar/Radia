# DtN-spectrum view of Kelvin-transformation coarse-mesh accuracy

These standalone scripts are the verified experiments behind the
`dtn_coarse_mesh` knowledge module
(`packages/radia-mcp/src/radia_mcp/radia_ngsolve/knowledge/dtn_coarse_mesh.py`).

**Idea.** Every open-boundary closure (Kelvin / BEM / PML / Robin) approximates the
one exterior Dirichlet-to-Neumann (Steklov–Poincaré) operator `Λ_ext`, whose sphere
eigenvalues are the mesh-independent ladder `λ_n = −(n+1)/R` (3D), `−n/R` (2D). The
discrete matrix `Λ_h` reproduces the LOW-degree eigenvalues accurately and almost
independently of mesh size `h`; the per-mode defect grows with degree `n`. Because a
compact source's field is dominated by low multipoles, a coarse Kelvin mesh already
resolves everything that matters — the empirical coarse-mesh accuracy, read off the
spectrum.

Every script PRINTS its result (no files written) and depends only on
`numpy` / `ngsolve` / `netgen` and the open `radia_mcp.radia_ngsolve` helpers
(`bem_integral`, `fem_bem_coupling`).

| `demo_k_kelvin_vs_bem_cost.py` | Kelvin sparse volume vs BEM dense surface — cost | `numerics` | Kelvin closure is SPARSE (~20 nnz/row, fill→0, assemble ~ms); the BEM exterior DtN is 100% DENSE (`nnz=ndof²`, O(ndof²) column-by-column assembly ~131→191 s at ndof 336→456) → ~10⁴× assembly gap. Kelvin pays more (volume) DoF but each is cheap; condensing to a DtN on Γ would re-create the dense block |
| `demo_l_minimal_ball.py` | How coarse can the Kelvin ball be? | `numerics` | the interior is irrelevant, so the ball is a curvature-limited thin SHELL: volume-tet count ≈ Γ-triangle count (~107 vs ~112), no real volume overhead; `p≥n` makes even this minimal ball exact (n=1→3e-5, n=3→8e-4) → the cost tracks Γ+order like a surface method, but the matrix stays sparse |
| `demo_m_multipole_ceiling.py` | On the coarsest ball, how many multipoles can you capture? | `numerics` | the ORDER is the multipole reach: on 112 Γ-triangles, p=3 is exact to n≈3, p=5→n≈5, p=7→n≈7, p=9→still 9e-6 at n=10, then it blows up once the harmonic out-resolves the surface (ceiling ~N_Γ·p). One coarse ball serves any source multipole n_src by raising p≥n_src |
| `demo_n_kelvin_approximates_bem.py` | Is Kelvin a SPARSE stand-in for the BEM exterior DtN? | `numerics` | both discretise the SAME exterior DtN on the SAME Γ; BEM is exact-exterior but DENSE (full ladder in one Γ×Γ matrix, nnz=ndof², ~67 s at 336 DoF), Kelvin is a SPARSE thin ball (~7% fill, ~20 nnz/row, ~ms) reproducing the ladder up to n≈p. On one coarse sphere, Kelvin `p≥n` MATCHES/beats BEM per-degree (n=1 3.3e-5 vs 7.4e-4; n=3 8.4e-4 vs 5.2e-3) → accuracy is bottlenecked by the SHARED surface, not the exterior treatment; Kelvin = "BEM truncated at multipole p", realised as a sparse volume |
| `demo_o_kelvin_vs_hmatrix.py` | Is Kelvin BETTER than H-matrix/FMM BEM? | `numerics` | both beat O(N²) by OPPOSITE mechanisms. H-matrix COMPRESSES the dense BEM: a well-separated off-diagonal block (50×56, gap 0.91) is numerically low-rank (rank 5 @1e-2 = 90% saved, 14 @1e-4) → O(N log N), but must build cluster-tree + ACA + singular near-field quadrature + inner V⁻¹ + indefinite coupling. Kelvin's SAME far block is **0 nonzeros** (structural sparsity, ~9–21 nnz/row) → sparse SPD, local integrals, ~ms, one solve with the interior FEM. Kelvin wins on simplicity for a sphere-able truncation; the genuine H-matrix edge is arbitrary NON-spherical Γ (see demo_p: exterior-field access is NOT a BEM-only advantage) |
| `demo_p_exterior_field_recovery.py` | Does Kelvin give the EXTERIOR field at any point, or only the interior? | `formulation` | the ball IS the compactified exterior, so the field at any exterior x (\|x\|>R) is the inverse Kelvin transform of the ball solution `u(x)=(R/ρ)u′(R²x/ρ²)` — one FE point-eval + conformal weight, no surface integral. Verified from just outside Γ (ρ=1.2) to far (ρ=20): dipole rel err 9e-7…2.4e-5, quadrupole 6e-4…2.3e-2 (the larger FAR relative error is the ball's ABSOLUTE geometry floor ~1e-5 amplified where the mapped value is tiny). Corrects the misconception that exterior-field access is a BEM-only advantage — Kelvin has it; the real BEM edge is arbitrary non-spherical Γ |
| `demo_q_material_surface_dtn.py` | Can the FEM-Kelvin matrix give the DtN on a MATERIAL surface, not just on Γ? | `formulation` | YES — the assembled FEM-Kelvin matrix is a universal DtN/Steklov generator. Condense (Schur = energy quotient) onto a body surface r=R_in<R_out and get the exterior-plus-open DtN there, ladder **(n+1)/R_in**, INDEPENDENT of R_out (Γ is just an arbitrary glue radius; ∞ baked in by Kelvin). Verified by p-convergence to ~1e-6 across R_in=0.3/0.4/0.5/0.7, and adversarially: a self-consistent two-region solve drives the growing-mode coefficient to 0 so the shell field IS the infinite-domain harmonic `(R_in/r)^(n+1)` (R_out cancels). The condensation surface need NOT be a sphere — a **cube body** gives a well-posed (SPD) dipole DtN 5.34 in the O(1/size) window. ⇒ FEM-Kelvin on an arbitrary body = a **sparse BEM approximation**: same exterior+open DtN operator BEM assembles densely, here from a sparse volume, ∞ exact, no Green function. Residual BEM niche: oscillatory high-frequency + high-aspect-ratio bodies |
| `demo_r_sparse_factorization_of_kernel.py` | Is FEM-Kelvin literally a sparse factorization of the dense Green's kernel? | `numerics` | YES — the dense BEM DtN kernel Λ is the **Schur complement** of the sparse FEM-Kelvin matrix A (eliminate A's volume DoFs → dense Λ), so A is a sparse representation of Λ obtained by ADDING auxiliary volume DoFs. Measured side-by-side on one Γ (R=1, both give the ladder): dense BEM 336 DoF / 100% fill / **70 s** (singular Green-fn quadrature) vs sparse FEM-Kelvin 768 DoF / 4.7% fill (~36 nnz/row) / **0.008 s** (local grad-grad). **DoF ×2.3 UP but assembly ~8800× faster, fill 100%→4.7%** — exactly "more DoF, less cost". A DIFFERENT sparsification from H-matrix (which keeps the same DoF and low-rank-compresses the dense blocks); FEM-Kelvin adds DoF for STRUCTURAL sparsity, SPD, no cluster-tree/ACA/inner-solve |
| `demo_s_bem_kelvin_equivalence.py` | In the refined limit, are BEM and FEM-Kelvin equivalent, and what rate-limits them? | `numerics` | EQUIVALENT (same continuous DtN) and both rate-limited by the TRUNCATION-SURFACE resolution. Measured (dipole, matched order 1, refine surface): maxh 0.50 → BEM 7.4e-4 / Kelvin 5.1e-3; maxh 0.40 → BEM 2.9e-4 / Kelvin 1.4e-3 — both fall at ~the same rate as the surface refines (the FEM-Kelvin volume is Galerkin-exact, the BEM quadrature converged, so neither is the bottleneck). The order-1 ~7× gap is a method CONSTANT, not a rate; the difference that SCALES is COST (sparse ~ms vs dense ~minutes), not accuracy |
| `demo_t_exterior_material.py` | Can the FEM-ized (Kelvin) open boundary carry MATERIAL in the exterior? | `formulation` | YES, and this is the genuine BEM differentiator. The exterior is a meshed (inverted) FE region, so any exterior `μ(x)` is just a transformed coefficient there. (1) uniform `μ_ext`: body-surface DtN scales as `μ_ext·(n+1)/R_in` (mechanism; but a constant μ keeps Laplace, so BEM can also do this trivial case). (2) INHOMOGENEOUS exterior — a magnetic shell `μ_s` in `[0.7,0.9]`, vacuum elsewhere — shifts the body-surface DtN OFF the vacuum ladder and FEM-Kelvin MATCHES the layered-sphere analytic (μ_s=5→5.268 vs 5.268; μ_s=20→6.414 vs 6.414; rel ~5e-5…3e-4). A free-space-Green BEM (and vacuum-exterior Kelvin/inverted-FE, Nabizadeh 2021 / Boulmezaoud) CANNOT represent a material shell in the exterior |
| `demo_u_layered_green_function.py` | Can FEM-Kelvin CONSTRUCT the layered ("Sommerfeld") Green's function cheaply, not just avoid it? | `formulation` | YES — its ACTION. The sparse SPD Kelvin matrix is the discrete Green's OPERATOR of the stratified exterior, so one solve (~43 nnz/row, fill<0.1%) reproduces the analytic layered profile `A r^n + B r^{-(n+1)}` THROUGH a magnetic shell `μ_s∈[0.7,0.9]` AND out to `r=10` via inverse Kelvin (rel `1e-4…3e-3`; n=1,2; μ_s=1/10/50) with **no Sommerfeld integral / special functions / branch cuts / surface-wave poles / singular quadrature** — the stratification is an FE coefficient, infinity is the Kelvin centre. Honest bounds: cheap = the **operator/action** & any single value; the FULL dense kernel is still `O(N²)` entries (= the Schur complement, demo_r — each entry cheap, not fewer); it is a NUMERICAL operator (accuracy = order × surface reach); the truly-hard planar (half-space) Sommerfeld case maps flat interfaces to spheres through the inversion centre (extended-Kelvin / radiating regime). Periodic-glue inverse map: `u_phys(x)=u'(x')`, NO `(R/ρ)` weight (that is demo_p's standalone-ball convention) |
| `demo_v_assemble_dtn_matrix.py` | Can the exterior DtN / Green MATRIX be assembled DIRECTLY, with exterior material? | `formulation` | YES — `Λ = A_GG − A_GR A_RR⁻¹ A_RG`, the **Schur complement** of the sparse SPD Kelvin-FEM operator (keep Γ DoFs, eliminate the rest): one sparse factorization + back-subs gives a small DENSE symmetric SPD boundary operator (impedance / macro-element / numerical Green matrix) for the **open + inhomogeneous** exterior — no free-space/Sommerfeld Green's function, infinity baked in. Because `μ(x)` rides as an FE coefficient, Λ is **material-loaded**: with a shell `μ_s∈[0.7,0.9]` outside `r=a=0.5`, Λ is `452×452` dense (from 12119 sparse DoF, A fill 0.35%, ~8 s, sym 0.0) and its generalized spectrum `(Λ,M_Γ)` matches the analytic vacuum ladder `(n+1)/a` AND its layered shift with exact `2n+1` multiplicities (μ_s=10: n=1 5.8655/5.8649, n=2 7.608/7.604; rel `1e-4…2e-3`). Honest scope: **n≥1** (dipole/inductance, quadrupole — magnetostatically relevant); n=0 monopole spurious (≈0, point ground has 0 capacity in 3D → needs finite ground). Full dense kernel still `O(N²)` entries (= this Λ) — cheap to **generate**, not smaller. New = exterior-material loading + `−(n+1)/R` spectral a-priori + sparse-Kelvin realization (Schur=DtN itself is standard: Demarcke 2011 / SBFEM) |
| `demo_w_nonspherical_dtn_matrix.py` | Can the DtN/Green matrix be assembled for a NON-spherical (arbitrary) body? | `formulation` | YES — same Schur condensation on a CUBE body. No analytic ladder for a cube, so verified by **octahedral symmetry**: the dipole stays 3-fold (T₁ᵤ) and the sphere's 5-fold quadrupole **SPLITS into 2+3** (E_g+T₂g) — an analytic-value-free proof Λ carries the body's symmetry = is the true exterior DtN. Cube half-side 0.4 → Λ `389×389` dense (sym 0, ~1 s): dipole `3.357×3`, quad `4.531×2 + 5.730×3`. Sphere calibration recovers `(n+1)/a`; cube dipole p-converges `3.545→3.365→3.342` (p=2,3,4); an exterior shell μ_s shifts it `3.357→4.370→5.007` (μ_s=1/10/50). The **body Γ may be arbitrary** while the Kelvin inversion surface stays a free spherical truncation → meets BEM's arbitrary-Γ parity (demo_o) **sparsely**, AND carries exterior material BEM can't |
| `demo_x_sommerfeld_isomorphism.py` | Is Kelvin-FEM ISOMORPHIC to the genuine (planar) SOMMERFELD half-space problem? | `formulation` | YES, conformally. Put the Kelvin inversion **centre ON the interface**: a plane-through-centre maps to itself, inversion preserves sign(z) so the two media z>0(c₁)/z<0(c₂) are preserved, ∞→centre → the **UNBOUNDED half-space ≅ a BOUNDED two-region ball** (the Sommerfeld radiation condition becomes a point condition at the centre). Verified vs the closed-form **static-Sommerfeld image** Green's function (β=(c₁−c₂)/(c₁+c₂)=−0.6; net-neutral dipole over c₁=1/c₂=4): matches in BOTH media AND the far field (inverse Kelvin) to **max 2.6e-3**, with NO Sommerfeld integral / branch cuts / surface-wave poles / special functions. Gotchas (each ~1e7× blow-up): mean-zero NumberSpace gauge (a 3D point ground has 0 capacity); EXACTLY neutral source (mesh-volume normalised); single-face periodic glue + `IfPos(z,c₁,c₂)` interface. Honest: static (image) limit; the wave Sommerfeld integral = the extended-Kelvin radiating regime (sugahara2025). **The strongest BEM differentiator: Kelvin-FEM is provably the same operator as the Sommerfeld layered problem, sparse, no layered Green's function** |
| `demo_y_sommerfeld_static_kernel.py` | The open-math SOMMERFELD reference the Kelvin-FEM is isomorphic to (multilayer) | `formulation` | A static layered-media Green's function for a planar stack (NOT in NGSolve/`ngbem` or the Radia core): reflected part = the **static Sommerfeld integral** `∫₀^∞ R(k) e^{−k(z+z′)} J₀(kρ) dk` with `R(k)` from the interface recursion. Two half-spaces → `R=r₀₁` const = the single image (demo_x); a SLAB → `R(k)` k-dependent = a true Sommerfeld integral = an infinite image series. **Verified**: numerical integral == closed image series to **1e-16** (slab); `r₁₂=0`/`t→0` limits collapse to the two-media image exactly. It's the independent reference certifying the demo_x isomorphism for **>2 media** (where a single image fails). Purpose = benchmark + complementary BEM capability (NOT for solving open BCs — Kelvin-FEM avoids the Sommerfeld integral). Gotcha: the k→0 boundary layer (~1/(2t)) is the delicate part (DC limit → 2-media image only as O(1/t); DCIM/tail methods exist). Pure numpy/scipy |
| `demo_z_sommerfeld_frequency_sweep.py` | Is Sommerfeld high-frequency only? can it be used at low frequency? | `formulation` | Separates KERNEL from FORMULATION. The layered Green's **kernel** is well-defined at ALL frequencies and EASIEST at low freq: the frequency-dependent half-space Sommerfeld integral matches the **PEC exact image** `exp(ik₀R_im)/R_im` from DC to deep wave (rel `9.7e-9 → 3.6e-6`, error **growing** with freq = the difficulty is the high-freq oscillatory tail); `k₀→0` reproduces demo_y; a lossy half-space converges at all freq. So Sommerfeld is **not inherently high-freq** (low-freq layered Sommerfeld = geophysical EM / eddy-current testing / induction logging, all quasi-static; sugahara2022 = eddy-current Kelvin). The famous "low-frequency breakdown" is an EFIE **conditioning** issue (loop-tree/Calderón) — a property of the integral *equation*, not the kernel. Grounds the **two-paper framing**: low-freq/quasi-static = the SA paper (Kelvin-FEM ≅ benign Sommerfeld); high-freq/radiating = extended-Kelvin+PML subproject (truncation-equivalence, not pure isomorphism) |
| `kelvin_exterior_mesh.py` | Does refining the exterior VOLUME mesh help? | `p_method` | `‖u_h−P_n‖≈1.5e-15` on every volume mesh (p≥n): the volume solve is Galerkin-exact → refining the exterior interior does nothing; only Γ's geometry (a surface effect) moves λ |
| `kelvin_exterior_mesh3.py` | Isolate Γ-surface vs interior volume | `p_method` | with the Γ surface fixed, λ is set by `∫_Ω|∇P_n|²/∮_Γ P_n²` — a fixed polynomial over a fixed domain; the exterior volume mesh enters nowhere. p=1<n control shows refinement only helps when the order is deficient |

| `inductance_dtn.py` | Is **inductance** DtN-certified like capacitance? | `datasheet` | external `L_ext` = the `n=1` (dipole) Steklov mode (identity `W_ext=½μ₀(n+1)/R∮φ²`, rel diff 0); `C↔n=0` exact, `L_ext↔n=1` defect `1.4e-3 (p=1)→7.6e-6 (p=3)`, floor=geometry, exterior-volume-irrelevant — the **dual of `C`**; NOT the `ngsbem` vector single-layer (different operator) |

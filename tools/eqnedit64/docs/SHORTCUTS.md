# Eqnedit64 ショートカット

## 覚え方

メニューまたはツールバーボタンからテンプレートや記号を挿入すると、
ステータス欄に「ショートカット・コーチ: 次回は …」と表示されます。
同じ操作を次回はキーで行う、という一操作ずつの学習を想定しています。
コーチは「ヘルプ → ショートカット・コーチ」でいつでも停止・再開できます。

`Ctrl+T`、`Ctrl+K`、`Ctrl+G`、`Ctrl+B` は接頭辞です。たとえば分数は
`Ctrl+T` を押して放し、次に `F` を押します。

## パレットバー（マウス）

ショートカットを覚えていなくても、**すべての記号と構造は2クリックで入る**。
Eqnedt32と同じ考え方で、ツールバーは目録そのものになっている。

- 1段目 = 分類タブ: 基本 / 解析 / 集合・記号 / 幾何 / ギリシャ
- 2段目 = 選択分類のパレット（最大5個）

分類内訳は次のとおり。

- 基本: 分数と根号 / 上下付き / 行列 / 括弧 / 装飾
- 解析: 関係演算子 / 演算子 / その他の記号 / 総和 / 積分
- 集合・記号: 矢印 / 集合記号 / 論理記号 / 総乗と集合演算 / 空白と点
- 幾何: 上線と下線
- ギリシャ: ギリシャ小文字 / ギリシャ大文字

セルを選択中は、ステータス欄に実際に挿入されるTeXが出る。クリック後は
常時表示のTeXソースでも同じ綴りを確認できる。
同じ目録は「挿入」メニューの同じ5分類からもたどれる（キーボード操作用）。

## GUI／TeXの2窓編集

上の構造キャンバスと下のTeXソースは、同じ数式をリアルタイムに編集します。
GUIで分数などを挿入すればTeXへ直ちに現れ、TeXを直接直せばGUIへ直ちに現れます。
ソースで閉じ括弧をまだ打っていない途中状態は、そのまま入力欄に保持されます。

ソースでの連続入力は1回のUndoにまとまります。キャンバスへ戻るか保存すると、
構造モデルが生成した正規化済みTeXへ揃います。TeXソース欄は常時表示され、
キャンバスまたはTeXソースをクリックした側をそのまま編集できます。
GUI／TeXの入力モードや専用の切替キーはありません。
長いTeXソースは欄幅で折り返します。TeXソースで`Enter`を押しても単なる空白改行には
ならず、キャンバスと同じ数式行区切り`\\`を作ります。構造を変えずソースだけを
改行する場合は`Shift+Enter`を使います。

## `Ctrl+T` テンプレート

Eqnedit32互換キーを先に示します。

| 次のキー | 動作 |
|---|---|
| `F` / `/` | 分数 / スラッシュ分数 |
| `H` / `L` / `J` | 上付き / 下付き / 上下付き |
| `I` | 積分 |
| `|` | 絶対値 |
| `R` / `N` | 平方根 / n乗根 |
| `S` / `P` | 総和 / 総乗 |
| `M` | 3×3行列 |
| `U` | 下側の注記（TeX `\underset`） |

| 次のキー | 動作 |

| `B` / `G` / `E` | 角括弧 / 波括弧 / 山括弧 |
| `V` / `Q` / `W` | ベクトル矢印 / ハット / チルダ |

## `Ctrl+G` ギリシャ文字

`A B G D E Z H T I K L M N X P R S U F C Y O` が、それぞれ
`α β γ δ ε ζ η θ ι κ λ μ ν ξ π ρ σ υ φ χ ψ ω` になります。
対応する大文字がある文字は `Shift` を併用します。

## `Ctrl+B` ベクトル文字

`Ctrl+B` の後に英字を入力すると、TeXの `\mathbf{...}` として挿入します。
`Shift` を併用すると大文字になります。すでに選択範囲があるときの `Ctrl+B` は、
選択した記号をその場でベクトル（太字）にします。

## 入力スタイルと配置

Eqnedit32と同じく、`Ctrl+Shift++`（`+` が出るキー）は数学、`Ctrl+Shift+E` は
文字列、`Ctrl+Shift+F` は関数、`Ctrl+Shift+I` は変数、`Ctrl+Shift+G` は
ギリシャ文字、`Ctrl+Shift+B` は行列・ベクトル入力へ切り替えます。

> 日本語キーボードでは `-` と `=` が同じ物理キーなので、`Ctrl+Shift+=` は
> 縮小になります。縮小には他の代替がないため、数学スタイルは `+` が出るキー
> （`;` のキー）を使ってください。英語キーボードでは `Ctrl+Shift+=` と
> `Ctrl+Shift++` は同じ打鍵です。この対応は
> `Eqnedit64.exe --ui-interaction-test` が実際のキー経路で検査します。
現在のスタイルはステータス欄に表示され、保存時にはTeXの構造へ変換されます。

`Ctrl+Shift+L` / `Ctrl+Shift+C` / `Ctrl+Shift+R` はキャンバス上の
左 / 中央 / 右揃えです。

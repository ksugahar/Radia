# analysis — Paper Figures and Analysis Scripts

Scripts for generating publication figures and performing detailed analysis.

## Files

| File | Description |
|------|-------------|
| `generate_paper_figures.py` | Generate all paper figures (fig1–fig4) |
| `demo_analysis_framework.py` | Analysis framework demo (frequency response, transient) |
| `analyze_dowell_prima.py` | Dowell–PRIMA comparison analysis |
| `analyze_tet_ordering.py` | Tetrahedral ordering analysis |
| `compare_symmetrized_solve.py` | Symmetrized vs unsymmetrized solve comparison |

## Outputs

Figures are saved to `figures/` subdirectory:

| Figure | Content |
|--------|---------|
| fig1 | PEEC matrix verification |
| fig2 | PRIMA accuracy comparison |
| fig3 | Magnetic-material coupling policy |
| fig4 | WPT coil (85 kHz) characteristics |
